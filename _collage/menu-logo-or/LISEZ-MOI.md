# Logo du menu en blanc et or (essais du 27/11/2026, PAS EN LIGNE)

Demande de Lilian (27/11 10h41) : le logo « AGENCE LDR » blanc avec le trait multicolore « ne fait pas premium », elle veut un blanc et or avec un bel or.
Trois versions montrées (image dans /mnt/project-files/site-agence-finition/logo-or/). Le CSS de chaque version est dans `essais.css` : il suffit de coller la version choisie (sans le préfixe `html[data-logo="N"]`) dans un `<style>` à la fin du menu maître, puis de recopier le menu dans les 3 copies.
La version 3 a besoin de la police Cinzel (Google Fonts, graisses 600 et 700).
